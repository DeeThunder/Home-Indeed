Before you get started.

Quick answers to help you decide whether Home Indeed is right for your church setup.

What is Home Indeed? +

Home Indeed is a native plugin for OBS Studio designed around church production tasks such as Bible passage browsing, lyrics and live overlay controls.

Which operating systems are supported? +

Version 1.2.0 is available for 64-bit Windows 10 and Windows 11. macOS and Linux builds are currently paused; check the official release page for updates.

Which Bible translations are included? +

The v1.2.0 release includes KJV, ASV, BBE and WEB. Refer to the release notes and in-app options for exact availability.

Can Home Indeed automatically detect scripture or lyrics from speech? +

Speech detection and automatic matching are experimental. Treat suggestions as assistive, verify the passage or lyric, and do not rely on them as an error-free live automation system.

Where can I get help or report a problem? +

Visit the Home Indeed GitHub repository to review documentation, release notes and available issue-reporting options.
